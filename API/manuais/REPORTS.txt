MANUAL DE INTEGRAÇÃO - REPORTS

Este módulo fornece dados agregados para o Dashboard do Professor, permitindo análises de desempenho, engajamento e evolução pedagógica.Base URL: /reportsParâmetros Comuns: * teacher_id (Obrigatório): ID do professor logado.year (Obrigatório): Ano letivo de referência (Ex: 2026).class_id (Opcional): Filtra os dados por uma turma específica.student_id (Opcional): Filtra os dados de um aluno (Requer class_id).

Desempenho por Assunto - Retorna o total de questões respondidas, acertos e erros agrupados por tema, ordenados pelos assuntos com maior índice de erro
- Endpoint: GET /reports/performance
- Postman: GET http://localhost:5000/reports/performance?teacher_id=1&year=2026&class_id=10&student_id=42
- Retorno
{
  "by_theme": [
    {
      "theme": "Sintaxe Python",
      "total": 120,
      "hits": 40,
      "misses": 80,
      "accuracy_rate": 33.33
    }
  ],
  "general_summary": {
    "total": 120,
    "hits": 40,
    "misses": 80
  }
}

- Endpoint: GET /reports/engagement
- Postman: GET http://localhost:5000/reports/engagement?teacher_id=1&year=2026

Top 10 Questões com mais Erros - Lista as 10 questões com maior volume de erros. A coluna difficulty só é retornada se o class_id for informado
- Endpoint: GET /reports/top-erros
- Postman:  GET http://localhost:5000/reports/top-errors?teacher_id=1&year=2026&class_id=10&student_id=42

Evolução Mensal - Fornece o percentual de acertos mês a mês. Aceita filtro opcional de tema (theme_id). A regua é um valor de referência visual para o gráfico.
- Endpoint: GET /reports/evolution
- Postman:  GET http://localhost:5000/reports/evolution?teacher_id=1&year=2026&class_id=10&student_id=42&theme_id=3&regua=75.0
