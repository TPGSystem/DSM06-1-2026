MANUAL DE INTEGRAÇÃO - REGIONS

Rota de Listagem (GET)
- Endpoint: /regions
- Retorno: JSON com a lista de todas as regiões/localidades do mapa do jogo.
- Postman: http://localhost:5000/regions

Consulta por ID (GET)
- Endpoint: /regions/<id>
- Postman: http://localhost:5000/regions/1

Regras Importantes
- Somente Leitura: Esta tabela é fundamental para o progresso do jogador (GamesSteps). Como as regiões são fixas no mapa, a API não permite edições.
- Uso no Game: Cada região representa uma etapa ou fase que o jogador deve completar para avançar na narrativa.
